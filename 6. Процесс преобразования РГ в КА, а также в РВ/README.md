# 6. Шаги выполнения процесса преобразования РГ в КА и РВ

Праволинейная регулярная грамматика для языка

```math
L_1 = \{\, a^n b^m : (n + m) \bmod 2 = 0 \,\}
```

имеет вид:

```text
S -> aA | bB | λ
A -> aS | bC
B -> aC | bS
C -> aB | bA | λ
```
