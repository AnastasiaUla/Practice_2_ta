# 8. Формальное доказательство непринадлежности заданного языка к классу РЯ

Рассматривается язык варианта 1:

```math
L_{27}=\{a^n b^l a^k\mid k\ge n+l\}.
```

Предположим, что $L_{27}$ является регулярным. Тогда по лемме о разрастании существует число $p$. Выберем слово

```math
w=a^p b^p a^{2p}.
```

Оно принадлежит $L_{27}$, поскольку $k=2p\ge n+l=p+p=2p$. Для любого допустимого разбиения $w=xyz$, где $|xy|\le p$ и $|y|>0$, подслово $y$ состоит только из букв `a`: $y=a^t$, $t>0$.

При $i=2$ получаем

```math
xy^2z=a^{p+t}b^pa^{2p}.
```

Здесь $n=p+t$, $l=p$, $k=2p$. Проверим условие языка:

```math
k\ge n+l \iff 2p\ge (p+t)+p \iff 2p\ge 2p+t \iff 0\ge t.
```

Но $t>0$, значит $0\ge t$ ложно. Следовательно, $k<n+l$, и полученное слово не принадлежит $L_{27}$, что противоречит лемме о разрастании.

Следовательно, язык $L_{27}$ не является регулярным.
